# Referencias y archivos

En este archivo se explican el proposito de cada archivo dentro del contexto. Estos son los archivos y sus funciones:

+ `README.md`: Documentación oficial y detallada del proyecto
+ `Especificaciones del proyecto`: En este archivo se explica el proposito del proyecto de forma simple y rápida
+ `Capacidades del proyecto`: En este archivo se explica lo que es capaz de hacer nuestro proyecto y sus resultados
+ `Decisiones tecnicas`: Aquí se explica el motivo de algunas decisiones en nuestro proyecto
+ `Objetivos`: Los objetivos generales y específicos del proyecto
+ `Estructura_del_proyecto`: Aquí se explica la estructura del informe técnico que debemos crear al final de la construcción de nuestra aplicación
+ `Estructura_del_trabajo`: Aquí se explica la estructura y contenido general del informe técnico. Destaca en las especificaciones del diagrama que se debe de crear
+ `ficha-de-contexto-agente-desarrollo.md`: Ficha de guía para agentes de código. Contiene un resumen y aclaraciones detalladas del proyecto en general
