# Objetivos generales y específicos

## Objetivo general

Crear un chatbot que se alimente de procesos y documentos penales para asistir tanto a abogados como a clientes en procesos judiciales

## Objetivos específicos

+ Diseñar un chatbot con UI similar a populares chatbots (ChatGPT, Claude, Gemini, Deepseek)
+ Implementar `RAG` con documentos judiciales para demostrar la capacidad de este técnica
+ Crear un demo (ya sea una web o un notebook) para completar las últimas partes del proyecto (veasé el arhivo `Estructura_del_proyecto.png`)
+ Diseñar un diagrama que cumpla con los requisitos del trabajo (veasé el archivo `Estructura_del_trabajo`)
