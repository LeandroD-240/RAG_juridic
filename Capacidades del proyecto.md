# Capacidades del proyecto

A pesar de asistir a 2 tipos de usuarios, el uso que le darán al chat es indistinto. El chat tiene las siguientes capacidades:

+ Enviar una respuesta según el prompt del usuario. La respuestas pueden ser resumenes, QAs, análisis, etc.
+ Recibir documentos en caso de ser enviados. **Aclaración:** Los documentos que envien los usuarios puede ser de cualquier tipo, pero están dirigidos a un ambito de derecho penal. Cualquier otro tipo de archivo con otro contexto (ya sea de derecho o no) es aceptado pero no estará enfocado
+ Crear diagramas, tablas y lineas de tiempo según se requieran (*e.g.* tablas de tiempo en cadena según el delito, infracción, incumplimiento, etc)
